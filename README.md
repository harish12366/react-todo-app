# React Todo App

A responsive Todo application built using React and CSS with a modern dark-themed user interface.

## Features

- Add new tasks with name and description
- Display tasks dynamically
- Edit tasks using inline editing
- Delete tasks
- Update task status (Completed / Not Completed)
- Filter tasks by status
- Dynamic task statistics (Total, Completed, Pending)
- Form validation with inline error messages
- Clear form functionality
- Hide and show all tasks
- Responsive user interface

## Tech Stack

- React.js
- JavaScript
- HTML5
- CSS3
- Vite
